# Changelog

Notable changes to Doclyro are documented here. This file begins with the open-source foundation work; earlier development history is summarized in the existing release and technical notes.

## Unreleased

### Added
- Contribution guidelines and pull request guidance.
- Community Code of Conduct.
- GitHub issue templates for bug reports and feature proposals.
- Continuous integration for Python tests and JavaScript syntax checks.

### Changed
- Security documentation now consistently identifies the project as Doclyro.
- Corrected stale operation counts and documented the PyMuPDF AGPL-3.0 licensing constraint; final project-wide license selection remains blocked pending maintainer decision.

### Notes
- No application runtime, API, operation handler, database, or deployment configuration is changed by this foundation update.
- Historical operation counts in existing documentation are inconsistent and remain an explicit documentation-audit item; use the live `/api/tools` endpoint as the runtime source of truth.
- License provenance and bundled third-party asset review remain required before presenting the repository as fully cleared for broad external contributions.
